Title : The Core Workflow Git
Category : General
Keywords : Git commands
Tags : git commit, git add

git status: Shows modified, staged, or untracked files.

git add <file>: Stages a specific file for the next commit.

git add .: Stages all modified and new files at once.

git commit -m "message": Saves the staged snapshot to project history.

git commit -am "message": Stages tracked files and commits them in one step.
